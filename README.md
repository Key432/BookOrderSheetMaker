# 本のたより — 書籍注文票作成サイト

書店へ持っていく書籍取り寄せ依頼票を作る、静的なWebアプリです。HTML / CSS / JavaScriptのみで動作し、GitHub Pagesに配置できます。サーバー、APIキー、外部パッケージのインストールは不要です。

## 機能

- ISBN-10 / ISBN-13を入力するとopenBDから書名・著者・出版社・取得可能な税込価格を自動入力。入力後は内容を確認して追加します。
- タイトル・著者・出版社・ISBN・税込価格の手動入力と編集。
- 注文リストと「後で買う」の相互移動。削除・移動の取り消し。
- 注文者の名前・電話番号、注文リストの参考合計金額。
- 注文リスト、「後で買う」、注文者情報、入力途中のフォームを入力のたびにlocalStorageへ自動保存。
- 注文リストのみをA4縦の依頼票として印刷。長いリストでは表の見出しを繰り返し、書籍ごとの行の途中での改ページを防ぎます。
- スマートフォン表示、キーボード操作、印刷プレビュー、PDF保存。

価格が未登録、税抜価格のみ、外貨価格の場合、税込価格は空欄になります。価格未入力の本を合計から除外したうえで、その冊数を画面・注文票に明記します。実際の価格・納期・取り寄せの可否は書店に確認してください。

書誌情報提供元：[openBD](https://openbd.jp/)、[API仕様](https://openbd.jp/spec/)。ISBN検索で送信するのはISBNのみです。連絡先とリストをサーバーへ送信する機能はありません。

## ローカルで実行

Node.js 20以上を使います。依存パッケージはありません。

```sh
npm run dev
```

表示される `http://127.0.0.1:4173` を開いてください。ES Modulesを使用するため、HTMLをファイルとして直接開かず、HTTPで配信してください。

```sh
npm test
npm run build
```

`dist/` に配信用のファイルを生成します。

## GitHub Pagesで公開

1. このプロジェクトをGitHubリポジトリの`main`ブランチへpushします。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
3. **Actions → Deploy to GitHub Pages → Run workflow** を実行します。以後は`main`へのpushで自動デプロイします。
4. デプロイ後、Actionsの`github-pages`環境に公開URLが表示されます。

ワークフローは `.github/workflows/pages.yml` にあります。`main`以外のブランチを使う場合は、ワークフローの`branches`を変更してください。全てのアセットとモジュールを相対URLで参照しているため、`https://USER.github.io/REPOSITORY/` のプロジェクトサイトでも動作します。

## 印刷

本を注文リストに追加し、必要に応じて注文者情報を入力して「注文票を確認・印刷」を押します。印刷画面ではA4・縦を選択してください。ブラウザーのヘッダーとフッターを無効にすると、注文票以外のURLや日時が入りません。PDFにする場合は送信先に「PDFに保存」を選択します。「後で買う」は印刷されません。

## 保存について

保存はブラウザー・オリジン単位です。別のブラウザー、端末、公開先のURLには同期されません。サイトデータの削除やプライベートブラウジング終了によりデータが消える場合があります。localStorageを利用できない場合は画面に警告し、保存済みデータを読み取れない場合には既存データの上書きを停止します。
